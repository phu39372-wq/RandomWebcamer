# Random Webcam (iOS)

Приложение показывает случайную публичную веб-камеру из официальной базы
Windy Webcams API (~65 000 камер, владельцы которых согласились на публикацию
через сервис Windy). При загрузке новой камеры воспроизводится звук затвора
(можно отключить кнопкой-колонкой в приложении).

## 1. Получите бесплатный API-ключ

Зарегистрируйтесь на https://api.windy.com/keys, создайте ключ для Webcams API.

## 2. Загрузите этот проект на GitHub

Загрузите ВСЕ файлы и папки из этого архива в ваш репозиторий (как и раньше).

## 3. ВАЖНЫЙ ШАГ: переименуйте папку github → .github

Из-за того, что Windows/архиваторы иногда теряют папки с точкой в начале
имени при загрузке, в этом архиве папка называется `github` (без точки).

После загрузки на GitHub:
1. Откройте файл `github/workflows/build.yml` в репозитории
2. Нажмите карандаш (Edit this file)
3. В поле пути наверху допишите точку в начале, чтобы получилось:
   `.github/workflows/build.yml`
4. Нажмите Commit changes

Без этого шага GitHub Actions не увидит workflow и вкладка Actions
останется пустой.

## 4. Добавьте секрет с API-ключом

Settings → Secrets and variables → Actions → New repository secret:
- Name: `WINDY_API_KEY`
- Value: ваш ключ

## 5. Запустите сборку

Вкладка Actions → дождитесь зелёной галочки (4-6 минут) → скачайте
артефакт `RandomWebcam-ipa` → распакуйте → внутри `RandomWebcam.ipa`

## 6. Установка на iPhone через Sideloadly

1. Скачайте https://sideloadly.io/
2. Подключите iPhone, разблокируйте
3. Перетащите `RandomWebcam.ipa` на иконку IPA в Sideloadly
4. Выберите Apple ID, нажмите Start
5. На iPhone: Настройки → Основные → VPN и управление устройством →
   выберите Apple ID → Довериться
6. Если попросит — включите Режим разработчика и перезагрузите

Бесплатный Apple ID даёт 7 дней работы приложения, затем нужно
пересобрать/переустановить тем же способом.
