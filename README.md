# Тёмный подвал

Оригинальный хоррор для iPhone (SwiftUI + SpriteKit). Тёмный лабиринт, фонарик с батарейкой и существо,
которое тебя ищет. Собери 4 предохранителя, найди зелёный выход и сбеги.

## Управление (горизонтальный экран)
- Левая половина экрана: двигай пальцем, появится джойстик.
- Кнопка с лампочкой справа внизу: включить или выключить фонарик.
- Включённый фонарик расходует батарейку и заметен существу издалека. Выключенный почти не виден,
  но и ты почти ничего не видишь.
- С каждым предохранителем существо становится быстрее. Рядом с ним телефон вибрирует всё чаще.

## Сборка IPA без Mac
1. Создай репозиторий на GitHub и загрузи туда содержимое папки (`Sources`, `project.yml`, `README.md`).
2. Файл `.github/workflows/build.yml` создай через «Add file → Create new file» с таким же путём
   и вставь в него содержимое из архива.
3. **Actions → Build unsigned IPA → Run workflow**. Через несколько минут скачай `DarkBasement-ipa`.
4. Поставь IPA через Sideloadly (бесплатный Apple ID, 7 дней).
